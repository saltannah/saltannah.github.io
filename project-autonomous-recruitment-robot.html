Project 001 / Mechanical

Autonomous Recruitment Robot

A recruitment robot mechanism centered on reliable flyer dispensing, spring behavior, and manufacturable CAD for custom 3D-printed parts.

TimelineNov 2024 -> Jun 2025
CategoryMechanical design
FocusFlyer dispenser
Overview

Designed a spring-loaded flyer dispensing mechanism in CAD and validated key design choices for tolerance, print orientation, and repeatable motion.

Highlights
  • Modeled mechanism components for a compact autonomous recruitment robot.
  • Evaluated spring behavior and release geometry for reliable flyer dispensing.
  • Adjusted tolerances and 3D print orientation for manufacturability.
