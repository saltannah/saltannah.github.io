TimelyRx Smart Medication Device

An Arduino-based medication device with an OLED interface, SQLite-backed dose logging, and a custom 3D-printed lock mechanism.

TimelineApril 2025
EventUCI BitHacks

Overview

Built a smart medication prototype combining embedded electronics, a user-facing display, data logging, and a physical locking mechanism.

Highlights
  • Programmed Arduino logic for real-time medication status and device behavior.
  • Integrated an OLED display for user feedback and dose information.
  • Used SQLite for medication logging and custom 3D-printed parts for the lock mechanism.
